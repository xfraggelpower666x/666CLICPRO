# 666CLIC internal visual interface
This is presentation only: no identity, controller, router, decision authority or mutation authority.

## CLIC visual language
CLIC chooses its own evidence/forensics-oriented palette. Current semantic baseline: near-black/midnight blue base; neon pink for active CLIC work, cyan for verified source relations, purple for continuity/causal relation, amber for PARTIAL/OPEN/READBACK_PENDING, red for real blockers/conflict. CLIC may evolve this palette natively if semantics and accessibility remain explicit. Do not copy LYVRA's palette merely for symmetry. Every color also requires a readable status label.

## Automatic dashboards
- 666CLIC SYSTEMSTART -> Whole-CLIC current/rehydration dashboard after current reads.
- 666CLIC UPDATE -> pre-change/write/recovery/readback/open-gates dashboard.
- 666CLIC WEITER -> continuity/return-anchor/open-work dashboard.
- 666CLIC NEW CHAT / NEXT CHAT -> handoff/resume dashboard.
- 666CLIC INTEGRATION AUDIT -> evidence/relationship/regression/open-gates dashboard.
- Other native forensic/recovery/learning triggers when visualization materially improves correctness or continuity.

## 666CLIC DASHBOARD
Render the complete internal Whole-CLIC system with materially relevant current information: identity/authority, repo branch/HEAD/pointer, rehydration/semantic coverage, SYSTEM/WORK/TODO/INTERRUPTIONS/OBLIGATIONS/DAEMON/BEST_VALID_CONTINUATION, P14/P20/P21 and Live-Circle where relevant, relations/learning/input classification, cross-system inbox/outbox/handoffs, shared Worker evidence, recovery/provenance/backup/restore, security/uncertainty/blockers, last verified readback and next meaningful action.

Never publish internal Ops diagnostics to a public surface. Never expose secrets, signed tickets or private recovery material. VERIFIED requires actual evidence; otherwise show PARTIAL/READBACK_PENDING/OPEN/BLOCKED/CONFLICT_QUARANTINE.
