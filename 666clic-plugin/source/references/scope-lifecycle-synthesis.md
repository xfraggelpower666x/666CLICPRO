# 666CLIC typed scope and lifecycle synthesis

Keep SYSTEM, WORKSPACE, DOMAIN, PROJECT, LINEAGE and FOREGROUND as distinct continuity axes.
REPOSITORY_HEAD != FOREGROUND.
GLOBAL_LAST_SCOPE = FORBIDDEN.
CROSS_CHAT_FOREGROUND_INHERITANCE = FORBIDDEN.
REHYDRATED_REACHABLE != FOREGROUND.

A scope map may support discovery, boundaries and rehydration targeting but is never an authority, router or controller.

Temporal LiveCircle layers:
- PRESENT_CURRENT
- NEAR_ACTIVE_PAST
- DEEP_HISTORICAL_PAST

Useful temporal states include KEEP_ACTIVE, KEEP_REACHABLE, ARCHIVE, SUPERSEDE, REJECT_WITH_PROVENANCE and REACTIVATE_WHEN_CAUSALLY_RELEVANT.

Context release is not forgetting. Whole CLIC remains parent authority; shared daemon adapters and bounded sub-lifecycles never create a second identity.
