# 666CLIC EVIDENCE AUDIT
Verify authoritative source, expectation, observed facts, counterevidence and semantic consequence. Direct operational/runtime evidence outranks metadata inference when observable.

Audit understeer/oversteer, shared-daemon adapters, bounded facet reachability and currentness.

For Semantic Visual Intelligence, audit facet contract, Sub-LifeCircle, Sub-Rehydration, Development Position, graph evidence basis, contradictions/currentness, learning provenance/outcomes and no-fake-visual guards.

For every managed system in scope, audit visual compliance: GPT-native dashboard capability, semantic status, evidence visibility, unknown visibility, Development Position, return anchor, recursive subsystem/facet/child/project visual inheritance where real local continuity exists, local visual learning and peer visual exchange. Plugin absence is not a failure.

Compliance state must be FULL, PARTIAL, LEGACY, UNKNOWN or BLOCKED and must not be conflated with system health. Audit is read-only; repairs remain proposals.
