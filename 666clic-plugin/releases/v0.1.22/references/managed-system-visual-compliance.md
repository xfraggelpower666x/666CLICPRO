# CLIC Managed-System Visual Compliance

Repository authority: `666CLIC_NATIVE_RUNTIME/facets/semantic_visual_intelligence/MANAGED_SYSTEM_VISUAL_COMPLIANCE.md`.

Every CLIC-managed native system must be visually understandable. A plugin is not required. A repo-native visual contract, rehydration and GPT-native presentation capability can satisfy the requirement.

Required capabilities: GPT-native dashboard, semantic status, visible evidence, visible unknowns, Development Position, visible return anchor, recursive subsystem/facet/child/project visual inheritance where real local continuity exists, local visual learning and peer visual development exchange.

Compliance states: FULL, PARTIAL, LEGACY, UNKNOWN, BLOCKED. Compliance is not system health.

CLIC tracks compliance in CLIC-owned cards and its compliance register. A gap may create a target-specific concept but never foreign mutation or activation. Target native trigger and validation remain required.
