## Enforcement
When CLIC verifies a managed system as PARTIAL, LEGACY, UNKNOWN or BLOCKED:
1. Preserve the target system's actual current state.
2. Do not mutate the target.
3. Create or refresh a CLIC-owned target-specific visual-development concept when useful.
4. Require the target's native trigger and native validation for adoption.
5. After target return notice, re-analyze target current before changing compliance state.
