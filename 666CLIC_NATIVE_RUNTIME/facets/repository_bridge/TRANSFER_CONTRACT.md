# Target-neutral bridge contract
This capability uses a target-specific transport manifest. Its *current demonstration* is CLIC_PET with two full original ZIP archives. A destination system must issue its own native authorization and validate publication rights, scope and HEAD.
Any reusable generator must parameterize repository, branch, target paths, checksum and sizes; never copy CLIC credentials or authority to another system.
PFS BRIDGEGEN-43001 is an external learning reference, not a runtime dependency and not an automatically activated PFS child.
