## Why relevant
666STREAM already separates repository authority from chat-local project foreground and preserves project continuity through PROJECT_MAP, SESSION_GOVERNOR and Temporal LiveCircle semantics. A project-scoped visual learning contract could add outcome-backed evidence/status learning without introducing a global active project or shared memory.
